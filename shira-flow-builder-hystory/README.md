# Shira Flow Builder History

Това е папка за постоянна история и техническа памет за работата по Shira Flow Builder (предвидена да се държи като локално Git хранилище; в пакета не е инициализирано).

## За следваща сесия на Codex

1. Прочети целия `SESSION_HISTORY.md`, преди да редактираш flow или tool.
2. Провери дали документацията в `shira-flow-builder-guide/` и `keen-admin-guide/` (в същия пакет) е обновена. При промяна тя има предимство пред старите бележки.
3. Провери текущите файлове и Git status в проекта, без да презаписваш промени на потребителя.
4. След завършена задача допълни `SESSION_HISTORY.md` с дата, резултат, проверка и нови открития и, ако папката е Git хранилище, направи локален commit.

Основният запис е [SESSION_HISTORY.md](SESSION_HISTORY.md).

## Правила за съдържанието

- Не се записват API ключове, deployment токени, пароли, cookies или други тайни.
- Не се записва per-project състояние: абсолютни пътища на конкретна машина и реални space / agent / session / correlation id-та се заменят с placeholders (`<project-root>`, `<space-id>`, …).
- Записват се проверени договори, точни пътища спрямо проекта (`<project-root>/src/...`), архитектурни решения, проблеми и резултати от тестове.
- Непотвърдените предположения се обозначават като такива.
- Този файл е постоянна памет на диска. Нова AI сесия няма автоматично да знае съдържанието му — трябва първо да го прочете.
